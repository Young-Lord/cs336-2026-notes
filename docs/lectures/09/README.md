# Lecture 9: Scaling Laws

**讲师**：Tatsu Hashimoto · **主题**：缩放定律（Scaling Laws）

## 本讲内容

上一讲（第八讲）Tatsu 讲了并行的各种系统细节；这一讲他暂时离开系统的土地，回到深度学习本身，开启"缩放定律"这一主题。这是基础篇：从历史（贝尔实验室 1993、Hestness 2017、Kaplan、Chinchilla）讲到幂律（power law）公式、最优配置与计算最优。后续还有一讲进阶版（现代开源模型技术报告、μP、参数初始化、优化器），不过今天只讲最基础、也最经典的内容。这一讲的核心问题是：**你有一万块 B200、一个月，要训练一个开源大语言模型——怎么不靠"在百万美元的大运行上调超参"，就能确保大训练成功？** 答案就是缩放定律：在小规模上完成所有优化，用一条简单、稳健的规则把"小规模行为"外推到"大规模行为"。

讲次分为三大部分。**第一部分**是缩放定律的背景与历史：把缩放定律连接到经典机器学习的泛化界与经验样本复杂度；最早的（数据）缩放定律论文其实可以追溯到 1993 年贝尔实验室的 Cortes 与 Vapnik；再经过 Banko 和 Brill 的对数线性规律、Kolachina 等人的机器翻译幂律，到 Hestness 2017 那个"超越时代"的神经缩放工作（涌现、按计算缩放、速度等于准确率）。**第二部分**是数据缩放定律：为什么 log-log 图上误差对数据量是直线（幂律）；均值估计玩具例子给出的 $\sigma^2/n$ 与 $1/n^{\alpha}$ 多项式衰减；神经缩放那慢得多的指数（$-0.1$、$-0.3$）如何让人联想到非参数回归的维度灾难（$n^{-1/d}$）；以及数据构成（截距变、斜率不变）、数据混合、数据重复（4 epoch 内无伤、之后变差）、无限计算设定下的"干预只改截距不改斜率"、数据过滤的尺度依赖性。**第三部分**是模型工程缩放与计算最优：用缩放定律回答架构（Transformer 对 LSTM、Tay 等人的跨架构研究）、优化器（SGD 对 Adam，截距不同但斜率相似）、深度/宽度（宽深比是尺度不变量、最优值约在 $d_{\text{model}} \approx 100$）、batch size（临界 batch size、$B_{crit} = E_{min}/S_{min}$、噪声受限与偏差受限）、学习率（$1/\text{width}$ 规则与 μP）这些超参数问题；然后是"更多数据还是更大模型"的联合缩放定律（Rosenfeld、Kaplan 的 $n^{-\alpha} + m^{-\beta} + C$），以及著名的 Kaplan 对 Chinchilla 之争——三种拟合方法（下包络、ISOFLOP、联合拟合）、计算最优的完整拉格朗日推导（$N_{opt} \propto C^{\frac{\beta}{\alpha+\beta}}$）、分歧的两种解释（Porian 等人的"小决定累积"与 Pearce 和 Song 的"非 embedding 参数与小规模非线性"）、Besiroglu 等人对方法三的数据取证，以及"训练最优不等于部署最优"——推理成本让前沿模型普遍"过训练"（从 GPT-3 的 2 token/参数到 Llama 3 70B 的 215 token/参数）。

## 本讲要点

- **缩放定律是"先小后大"的工程范式**：在大规模上反复调超参太贵，缩放定律在小规模上完成优化，再用简单规则外推——前提是小规模与大规模被简单、稳健的规律连接起来。大实验室里它近乎一种"信念"；
- **缩放定律有很长的历史**：最早的（数据）缩放定律是 1993 年贝尔实验室（Cortes 与 Vapnik）——在小样本上拟合分类器、拟合误差衰减曲线再外推性能；从 Banko 和 Brill 的对数线性、Kolachina 的机器翻译幂律，到 Hestness 2017 就已预言涌现、按计算缩放与"速度等于准确率"；
- **数据缩放定律**：固定训练流程、模型大于数据，log 误差对 log 数据量是直线 ⟺ 幂律 $E = kn^{-\alpha}$。均值估计给出 $\mathbb{E}[(\hat\mu - \mu)^2] = \sigma^2/n$（即 $y = -x + C$）；但神经缩放指数只有约 $-0.1$～$-0.3$，慢得多——这让人联想到**非参数回归的维度灾难**（$d$ 维误差 $n^{-1/d}$，即斜率 $-1/d$），神经网络大致像"在约 10 维工作的非参数回归器"；
- **数据构成影响截距、不影响斜率**：混合最优值在小规模与大规模一致（DataComp 的实证结论）；干预（正则化、集成）也几乎只改截距——所以"模型类决定斜率"；
- **数据重复与有限数据**：标准配方下重复到约 4 epoch 无伤，超过后实际缩放定律明显变差；计算无限增长而数据不增长的时代，数据过滤策略是**尺度依赖**的——计算越多，过滤器越宽松；
- **模型工程缩放**：用缩放定律回答超参数问题——架构（GLU 的缩放趋势优于 vanilla、Performer 不行）、优化器（SGD 对 Adam 截距不同但斜率几乎相同）、宽深比（**尺度不变量**，最优 $d_{\text{model}}$ 约 100）——关键教训是"跨尺度的可预测性是工程出来的，缩放定律不是魔法"；
- **临界 batch size**：batch 增大先是**噪声受限**（完美缩放、方差削减），达到梯度噪声尺度后进入**偏差受限**（不再受益）；按"选目标损失 → 扫 batch → 记录步数 $S$ 与样例数 $E$ → 拟合 $S_{min}, E_{min}$"估计，$B_{crit} = E_{min}/S_{min}$，它随目标损失变小（计算变大）而按幂律增长；
- **联合缩放定律**：$E = n^{-\alpha} + m^{-\beta} + C$ 把数据量与模型规模统一起来（极限下分别退化为纯模型缩放与纯数据缩放），可在小规模拟合后精确外推到大计算区域；
- **计算最优的推导**：对 $L = E + A/N^{\alpha} + B/D^{\beta}$ 在约束 $C \approx 6ND$ 下做拉格朗日优化，得到 $N_{opt} \propto C^{\frac{\beta}{\alpha+\beta}}$、$D_{opt} \propto C^{\frac{\alpha}{\alpha+\beta}}$——**分配指数由"另一个量"的指数决定**；Kaplan（$C^{0.73}/C^{0.27}$）与 Chinchilla 三种方法（约 $C^{0.5}/C^{0.5}$，方法三 $C^{0.46}/C^{0.54}$）的分歧来自参数计数（最后一层/embedding）、warmup 与 batch 调优等"小决定"的累积，以及非 embedding 参数在小规模引入的非线性；方法三本身被 Besiroglu 等人的数据取证证明是欠拟合，重拟合后恰好回到 20∶1；
- **训练最优不是部署最优**：真实部署中大部分计算是推理，所以前沿模型普遍"过训练"——GPT-3 只有 2 token/参数，Chinchilla 20，Mistral 7B 到 110，Llama 3 70B 到 215；预期使用越多，越值得付前期训练成本。
