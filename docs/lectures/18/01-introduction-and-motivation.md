# 开场与动机：为什么推理值得研究

## 客座讲师：Dan Fu

这一讲很特别：它不是本课程的常规讲师（Percy 或 Tatsu）主讲，而是一场**客座讲座（guest lecture）**。站在讲台上的是 **Dan Fu**——他现在是 UCSD（加州大学圣迭戈分校）的助理教授，同时在 **Together AI** 做研究；本讲开场时，他先感谢了 Percy 的邀请。

Dan 开场时这样概括这堂课的位置：这门课的大部分内容都在讲**训练**——怎么训练语言模型，怎么把模型训练到能跟你对话的程度。而他今天要讲的是**另一面**：一旦你有了这样的模型，从"另一侧"看起来是什么样？也就是**服务（serving）这些模型**、**做推理（inference）**——把这些东西从"电"变成 token、再从 token 变成"智能"。除此之外，他还要分享一些从推理视角出发的、有趣的研究问题。

## 开场动机：我们正处在一场新的工业革命里

Dan 的第一个观点是：围绕这些模型及其能力，我们正在经历一场近乎"新的工业革命"（new industrial revolution）。他用的例子还是自己两年前找工作时做的幻灯片，所以具体例子已经有点旧了，但要点依然成立：今天的模型可以做到人类水平的文本生成与代码生成（Cursor、Claude Code、GPT-4 这类工具），可以生成图像和视频、也可以理解图像和视频，开始理解新的模态，还开始在科学领域（生物、健康、DNA 模型等）找到应用。

什么驱动了这些进步？长期以来驱动 Dan 研究的一个核心问题是：**是什么让这些进步成为可能？下一代又该如何改进？** 而他给出的第一个答案是**规模（scale）**。他展示了一张已经相当老的图，但模型的规模确实在以一种夸张的方式增长：

- **2018 年**（Dan 自嘲"我博士刚开始的远古时代"），最大的模型约 **1 亿（$10^8$）参数**，当时大家觉得"天哪这太疯狂了"；
- **2019 年**，出现了 GPT-2——当时人们觉得它太危险、不能发布（如今这门课里认真训练的话，你也能训练出一个 GPT-2 质量级的模型）；
- **今天**，开源模型已经达到**万亿（$10^{12}$）参数**甚至更多，前沿模型大概是 **5 到 10 万亿参数**。

参数规模带来了一堆新能力：聊天、写代码、分析复杂文本、帮你做作业等等。但更值得注意的是**转变的速度比我们想象中快**——至少比 Dan 几年前博士刚开始时想象得快。

## 马车与马粪：一个关于"转型有多快"的历史类比

为了说明这种转型的速度，Dan 讲了一个历史故事（他特意提到，日期恰好对得上，很有意思）：

- **1902 年**，曼哈顿有 **13 万匹"工作马"（working horses）**。这些马不是养着玩的，它们扮演着关键的角色（运输等）。每匹马每天要产生好几磅的马粪——13 万匹马，就是实实在在的"马粪危机"；
- 当时甚至有为这个问题专门开的**学术会议**：1898 年纽约就开过一次"如何处理马粪"的会议，结论是"我们拿马粪毫无办法，你只能捏着鼻子忍下去"；
- 仅仅 **10 年后（1912 年）**，曼哈顿的汽车数量已经超过了马。几个世纪以来一直存在的马，就这样被汽车取代了。

Dan 认为，对语言模型、对我们做的很多事情来说，那个"1912 时刻"大概就发生在**去年**——至少对他而言，从去年开始，他写的大部分代码都借助语言模型完成，他团队里大多数人如此，他也要求自己的学生这样做（除了做作业的时候）。

## GPU 是新的石油，推理是把电变成智能的引擎

推动这一切规模增长的，是 GPU。在一种非常实在的意义上，可以说 **GPU 是新的石油**：我们看到的是成百上千亿美元的投资，甚至整个国家、整个主权财富基金都把 GPU 作为主要投资方向——历史总是在以有趣的方式押韵。

但 Dan 强调了一个常常被忽略的点：**推理（inference）才是真正关键的环节**。可以把推理想成一台"把电变成智能的引擎"——就像石油只有放进汽车、由发动机把它转化为有用的动能才有意义一样，**推理引擎、GPU kernel 这些软件，才是真正把 GPU 从"沙子"（Percy 喜欢把 GPU 比作沙子）变成我们今天能用的东西的环节**。

顺着这个思路：机器学习模型本质上只是一堆**运算构成的有向无环图（DAG）**，是一个存在于"以太"中的数学对象。而推理引擎、GPU kernel 这些软件，才是你必须真正去编程、把它们映射到具体 ML 运算上的东西。这门课里你写过一些——比如实现 Flash Attention（训练侧）——但**推理侧还有一整个世界级的复杂度**。

> **本讲最重要的一个信息**：如果你理解推理、理解推理引擎、理解支撑核心技术的 GPU kernel，你就能在机器学习算法上做**全栈式的创新（full-stack innovation）**——无论是新的调度算法、新的 kernel，还是新的架构。

## 本讲路线图

Dan 为本讲安排了两部分内容：

1. **一个 token 的一生（the lifetime of a token）**：当你向这些模型发出一个请求时，请求会经历什么？它如何穿过整个推理服务？在这个过程中有哪些有趣的选择要做？
2. **两个研究项目**：如果只拿出这个系统中的某些部分来研究，能提出什么问题、能做什么？——分别是本讲后半段的 **MegaKernel**（decode 加速）与 **Parcae**（循环语言模型）。

进入技术细节之前，Dan 快速做了一个"广告"：他代表两个组织。一个是 **UCSD**，他有自己的小实验室，本讲有一部分工作来自那里；另一个是 **Together AI**——一家人工智能云（有 GPU、推理、微调等业务），有深厚的研究背景（Percy 也是其中一员），本讲另一些工作来自那里。
