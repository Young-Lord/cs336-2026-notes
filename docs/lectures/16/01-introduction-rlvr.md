# 引言：从 RLHF 到 RLVR

## 开场：一条非常及时的新闻

这一讲是后训练系列的**第二讲**。我们要讲的是 **RLVR**（reinforcement learning from verifiable rewards，基于可验证奖励的强化学习）——这些年语言模型领域最激动人心的发展之一。Tatsu 开场就提到一条非常应景的新闻：就在上课前不久，OpenAI 的人宣布，他们用某个"思考模型"（thinking model）解决了一个长期悬而未决的重大公开数学难题。这类"思考模型"为什么能解出这种问题？**靠的正是本讲要讲的思考模型训练方法，也就是 RLVR。** 换句话说，这条新闻本身就是"你为什么要认真学这一讲"的最直接注脚。

## 我们站在哪里：从 ChatGPT 到 o1/r1

先回顾一下课程走到今天的位置。上一讲结束时，我们处在幻灯片左侧的状态：已经做完**指令微调（instruction tuning）**和**RLHF**，得到的是一个相当不错的东西——**ChatGPT**。而剩下的、也是近年模型能力上最大的增量，是"思考模型"这一支的现代发展：**模型能够进行非常长的思维链（chain-of-thought，CoT）推理，并解决数学、编码这类"可验证"的难题**。这一讲的目标，就是带我们从 ChatGPT 一路走到 o1/r1 级别的思考模型。

![课程迄今的路线：预训练 + RLHF 把你带到约 GPT-3.5，这一讲要到 o1/r1](/lectures/16/slide-02.png)

为什么上一讲结尾留下的是一个"沮丧"的注脚？因为 **RLHF 并不真正能带我们走到想去的地方，根本原因是过度优化（overoptimization）**。流程你是知道的：收集一堆偏好数据（很有用），训练一个奖励模型，然后对这个奖励模型做强化学习。但这条路径**在根本上受标注瓶颈（annotation bottleneck）制约**：你有一个奖励模型，就不能无限地把计算投入同一个奖励模型——迟早你会过拟合这个奖励模型。无论你把正则化做得多好，最终都会撞上过拟合问题。这相当令人沮丧，而且它并没有发挥出强化学习应有的潜力。

## 什么情况下 RL 能大放异彩：AlphaGo 的启示

如果你是一个坚定的强化学习信徒，你会指着 AlphaGo 这类例子说：在这些领域，RL 确实干得漂亮。那么，**我们做的 RLHF 与那些"RL 原生"领域之间，差别到底在哪？**

Tatsu 给出的答案（一种不精确但很有用的看法）：在 AlphaGo 里，**我们优化的恰恰就是想要的东西**——围棋的胜负条件，这个定义没有任何含糊之处。因此你可以往里面无限地投入计算：只要目标函数在改进，你就做得对。在某种意义上，这类问题是**搜索问题（search problems）**；而 RLHF 更像是**学习问题（learning problem）**——奖励模型本身只是人类偏好的一个近似，优化它不等于优化真正想要的东西。

![本讲目标：RLHF 因过度优化无法干净地缩放，能否回到 RL 真正擅长的领域——优化恰好是我们想要的东西？](/lectures/16/slide-03.png)

顺着这个思路，还存在一些别的领域——比如**形式数学（formal mathematics）**，甚至**自然语言数学**——具有"更可验证"的性质，因而更适合强化学习。这就是我们研究 RLVR 的动机：**算法在根本上不会有什么不同，但终点会出乎意料地不同。**

与课程其他部分一样，这一讲也分成两半：
