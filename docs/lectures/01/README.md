# 第 1 讲：开场与课程动机

Percy 以一句欢迎词开启了这门课："欢迎各位来到 CS336——Language Models From Scratch（从头构建语言模型）。"站在讲台上的是一支完整的教学团队：Percy 本人、Tatsu（Hashimoto）、Marcel、Herman 和 Steven，而他们为这一届同学带来的是 CS336 的**第三届**授课。在正式进入技术内容之前，团队先做了一轮快速的自我介绍。

## 教学团队的自我介绍

### Percy：从"小型"语言模型起步

Percy 开玩笑说，自己已经"做语言模型做了 20 年"，不过这 20 年大部分时间做的都是**小型**语言模型——"当然，放到今天的大格局里看，这些模型依然是小的"。他回忆道，两年前他和 Tatsu 刚开始教这门课时，并不太确定会发生什么，但结果让他们非常惊喜：有这么多人愿意学习如何从零构建语言模型，尤其是在**当下一个编码智能体可能已经能零样本地（零提示）写出一个语言模型**的时代。正因为如此，他特别高兴能看到在场的同学们依然想要真正理解语言模型的工作原理。

### Tatsu：架构与缩放的主讲人

Tatsu 是共同授课老师之一，之后会负责架构（architectures）与缩放（scaling）等"非常好玩的部分"。他说这是他在斯坦福任教以来教过的最有趣的一门课。他还分享了一个内部小梗：每年 Percy 都会调侃他，因为只要接手了架构部分，就意味着"每一年都要把全部讲义重写一遍，因为架构每年都在变"。但对 Tatsu 而言，这反而是头一回拥有的体验，他也很期待和同学们一起再走一遍这个过程。

### Marcel：回炉重修的"过来人"

Marcel 上过一遍这门课，这次是"返场"，因为上次实在太好玩了。他坦诚地补了一句："不过工作量确实很大。"他本人研究的是架构方向，做高阶梯度（higher-order gradients）和训练（training），很期待和大家一起工作。

### Herman：一年前还不懂 LLM 的助教

Herman 的自我介绍是全场最有画面感的：一年前的他还完全不懂大语言模型，在他看来，"token 是你在电子游戏里收集的东西，attention 是你说的那种注意力经济（attention economy）"。而在花大量时间上完这门课后，他现在已经在做 LLM 研究了，并且非常兴奋地成为今年的助教（TA）。

### Steven：第一次当 CA 的新人

Steven 是这门课的第一届课程助理（CA）。他的研究大致覆盖语言模型、理论以及一些数据效率（data efficiency）方向，同样很期待和大家见面。

## 第三届：什么变了，什么没变

这是这门课第三次开设。去年，教学团队决定把所有讲座上传到 YouTube（Spring 2025 那一届的录像现在就能看到），所以在场的部分同学可能已经看过往期的录像。那么今年有什么新东西？

首先，**"from scratch"哲学没有变**。团队依然坚信：通过从地基开始把一切亲手搭起来，你才能真正理解每个部件的工作原理。Percy 强调，这门课当然不会真的把一切都从零实现——那在一学期（quarter）的时间里根本装不下。过去两年，团队一直在反复打磨"配方"，搞清楚**哪些东西值得从零构建、哪些概念的单位时间价值最高**（prioritize high value-per-time concepts），一句话概括就是"别为了树木丢掉森林"（don't lose the forest for the trees）。

其次，正如 Tatsu 提到的，**即便只有一年，这个领域也变化巨大**。今年课程会在**混合专家**（mixture of experts）上花更多时间；而 agent 是当下最热门的话题，所以**长上下文**（long context）以及支撑它所需的技术，也会成为本学期的重点内容。

回顾整个开场：Percy 想传达的核心信息是，在这个"编码智能体都能零样本写出语言模型"的时代，依然有一群人愿意选择更难的路——亲手把语言模型一层层搭起来，真正搞懂它的工作原理。这正是 CS336 存在的意义。

## 本讲形式：一场"可执行"的讲座

值得一提的是这门课的呈现方式：**可执行讲座（executable lecture）**。整场讲座本质上就是一个 Python 程序，讲者"翻页"的过程就是逐步执行这段程序的过程——幻灯片的每一页都对应一段可运行、可检查的代码。因此你可以随时看到某个变量的取值、某段算法真正的执行路径，也能清楚看到整场讲座的层次结构。这门课的所有讲座材料与作业都会在课程网站（cs336.stanford.edu）上公开，上一届（Spring 2025）的讲座视频也已经发布在 YouTube 上。

## 本讲内容预告

这场讲座接下来会依次讨论：为什么会有这门课（研究者与技术底层脱节、语言模型的工业化、三种知识、苦涩的教训）；语言模型的历史与开源生态；课程信息与作业安排；五大部分的课程大纲（与五个作业一一对应）；然后立刻进入本讲第一个技术单元——tokenization，包括 tokenizer 基础与 Byte Pair Encoding（BPE）算法。
