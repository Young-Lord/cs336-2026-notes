# 近期的开源缩放配方

## 为什么最近的论文“细节变少了”

进入 2024 年下半年以后，一篇有趣的现象是：**开源模型发布论文里的缩放实验细节越来越少**。讲者的猜测是，核心的缩放机制——怎么做 Chinchilla、怎么做学习率缩放——现在已经被大家当作常识（taken for granted），所有人都默认你会做，所以论文里不再花大篇幅展示。本节快速过一遍几个有代表性的近期工作，主要目的是给你一个概览：**开源发布里，人们还在用缩放定律做什么。**

## Qwen 2.5 / Qwen 3：与 DeepSeek 同一套流程

**Qwen 2.5** 的做法和 DeepSeek 的分析如出一辙：需要调一批最优超参（batch size、学习率），于是做一堆缩放实验找出最优，然后写一条缩放律，用它预测最优——**甚至对 MoE 也这么干**。

到了 **Qwen 3**，基本就是“我们在 Qwen 2.5 已经搞定了，这次照做一遍”。也就是说，这已经变成了钉死最优学习率与 batch size 的**标准配方**的一部分，没有太多新意，但很实用。

## Kimi K2：MoE 稀疏度缩放

**Kimi K2（2026，本讲讨论的最新模型之一）** 以及其它近期的模型，关注的重点变成了 **MoE 缩放定律**。到了 2026 年，大家都知道怎么做 Chinchilla 或学习率缩放；新的问题是：**很多公司正在全面转向 MoE，那你是否训练了正确数量的激活参数（active parameters）？**

做法是：改变 FLOPs、观察损失，并对**不同的稀疏度（sparsity）水平**重复；由此定量地看出**稀疏度对损失是帮助还是伤害**。结论不出意外：给定 FLOPs，网络越稀疏，验证损失越好。但关键在于——有了“稀疏度–损失”的**定量关系**，你就能做出理性的架构决策：Kimi K2 据此选择了**稀疏度 48**，因为再往上就撞上了缩放损失的**递减收益（diminishing returns）**。

这正是“用缩放分析来论证架构决策”的典型例子。

## Hunyuan（2024）：MoE 的等 FLOPs 缩放

**Hunyuan** 是另一个开源 MoE（来自腾讯，2024）。一旦切换到 MoE，每家公司都得做一遍类似的“MoE 缩放律”，搞清楚激活参数量/稀疏度如何影响训练损失，然后重做一大堆前面的分析。Hunyuan 的做法是**固定稀疏度**、做等 FLOPs 式缩放，最终得到的数据与激活参数之比约为 **96∶1**。

## LLaMA 3（2024）：isoFLOP 与“计算→下游”缩放

**LLaMA 3** 也做了 isoFLOP 式缩放，得到的 token 与模型之比与 Chinchilla 类似但略有不同（约 39∶1）。在讲者看来，LLaMA 3 论文里**最有趣**的缩放内容其实是右侧那张图：

- 左图是常规缩放律：计算量越多，基准上的 log 概率一致地下降；
- 右图把 **log 损失与下游准确率**联系起来：损失越好，下游准确率越高。作者在这堆紫点上拟合了一条 **sigmoid**，用这条曲线来大致估计“这些模型会有多好”。

讲者提醒：你可以看到紫点相对曲线有**系统性偏差**，所以他并不完全相信这条曲线是“唯一的真理”；但它的确与“损失到准确率的 sigmoidal 映射”一致，这很有用——毕竟我们整堂课都在讲 log 损失，而损失与下游指标之间在很多情况下有**紧密的耦合**。

## MiniMax-01（2025）：架构缩放定律

**MiniMax-01**（去年的模型）做了一套很好的缩放实验，正是两讲前讲者所说的“缩放的一个重要用途”：**架构选择**。MiniMax 在 lightning attention（一种线性注意力）、softmax（全注意力）、以及两者混合的 hybrid 架构之间做选择，于是问：**这些架构怎么缩放？** 放大其中一种会不会比另一种差很多？

他们复现了 Kaplan 式的图：随着 FLOPs 增大，不同架构的学习曲线如何变化、不同计算量下需要多少参数。结论大体是：**hybrid、lightning、softmax 在缩放上基本相当，所需模型大小相似**。这一套图被用来论证他们最终部署系统里选用**混合架构**的合理性——这正是你基于缩放定律做决策的标准方式。

## 缩放配方总结

把前面的内容汇总，可以提炼出两份“食谱”：

**DeepSeek 配方**
- 假设大多数 transformer 超参对尺度不变；
- 只对 **batch / LR 做缩放分析**，得到最优缩放；
- 用 **isoFLOP 分析**确定模型尺寸；
- 用**分段线性学习率调度**（WSD）让 Chinchilla 缩放变得便宜。

**MiniCPM 配方**
- 用 **μP** 让 transformer + 学习率对尺度不变；
- 用分段线性调度（WSD）拿到做 **Chinchilla 方法三（曲线拟合）** 的样本。

而最近（2024 年底之后）的论文大多**不那么详细**：

| 模型 | 做了什么样的缩放 |
|------|------|
| Qwen | 只给 LR/batch（细节很少） |
| Kimi K2 | MoE 缩放 |
| LLaMA 3 / Hunyuan | 只做了 isoFLOP（没有其它缩放细节） |
| MiniMax | 架构选择/决策缩放 |

## 课堂问答：后训练时代，缩放还成立吗？

> **问题**：这一整节都在讲预训练阶段。现在后训练（post-training）已经成为保证质量的标准流程，那么缩放定律里**什么变了、什么没变**？

**Tatsu**：这仍然是一个很大的开放问题。目前还没有很好的办法做“把后训练也考虑进来的完全集成缩放”——因为后训练有时候会**根本性地改变你该做怎样的预训练**。最接近的思路是预训练里关于**覆盖度**（coverage）或**多样性**（diversity）的一些工作，它们试图预测后训练阶段会发生什么；但这些工作还很初期。对于“预训练与后训练如何协同”这个问题，目前还没有好的答案。
