# 开场与动机：为什么需要注意力替代方案

欢迎来到第四讲。Tatsu 开场先道了个歉：今天的幻灯片早上还没放上去，现在已经在课程网站上（以及 GitHub 上）了，大家可以边听边看。这一讲要聊的是**更进阶、更复杂的架构思想**。上一讲（第 3 讲）讲的是基础 transformer，以及如何调整它的各个零件把它变成现代语言模型；而今天要讲的，是在普通 transformer 之上**更进一步、更复杂的发展**。主题有两个，恰好对应 transformer 里最重要的两个块：

1. **注意力替代方案（attention alternatives）**：用架构手段把上下文长度推到非常长，这些方法大多把对序列长度的依赖从二次方降到**线性时间（linear time）**;
2. **混合专家模型（Mixture of Experts,MoE）**：改的是 MLP 那一块。MoE 能带来显著更好的**硬件利用率**——在同样的算力开销下拥有**更多的参数**。

先讲注意力。

## 大家都想要更长的上下文

动机很明确：**人们就是想要更长的上下文窗口**。你想往上下文里塞进很多东西，让模型拥有更多"知识"——比如一个 agent 要在一个很长的会话里同时操作很多事情。看看各家模型厂商随时间推出的上下文窗口大小（横轴是时间，纵轴是窗口大小，对数刻度），能清楚地看到**头部模型厂商之间"军备竞赛"式的竞争**：窗口越推越大，来支撑越来越复杂的工作负载。

![](/lectures/04/slide-02.png)

但长上下文是要付钱的。同一张幻灯片右侧的图展示了另一个成本视角：随着序列长度增长，网络的**前馈部分（feed forward）与注意力部分（attention）的计算成本之比**如何变化。可以看到：

- **前馈（FFN）**：初始时占比很大，但只随序列长度**线性**增长；
- **注意力（attention）**：它是所有位置之间的**全对全（all-to-all）连接**，是**二次方**的，所以序列一长，注意力成本迅速反超前馈。

曾经对大模型来说，在较短的序列长度下，**前馈是主导成本**。但随着序列变长，注意力越来越成为麻烦的来源。这就是本讲前半部分要解决的核心问题。

## 控制成本的"基本工具箱"

那么有什么基本手段来控制这些成本？两个方向，Tatsu 说一个上一讲已经谈过、另一个也会在后面讲到。

### 手段一：局部注意力 + 全局注意力的混合

把**局部注意力**（local attention）以各种混合（hybrid）的方式组合起来，来控制全局注意力的高成本。比如**每 8 层才做一次全局注意力，其余层都用很局部的注意力**，那全局注意力的成本就被大大控制了。

### 手段二：系统工程——常数因子真的非常重要

第二个手段是系统工程。Tatsu 强调，有一个**被严重低估的事实：常数因子（constant factors）极其重要**。这门课的一个主题就是"你要注意细节"——在经典理论导向的计算机科学传统里长大的学生很容易觉得"Big-O 才重要，线性还是二次方才是关键"。但近年在上下文与注意力成本上发生的最大变化之一，恰恰是 **FlashAttention**。

关于 FlashAttention，系统课和系统作业里会讲得非常细，这里只需要知道：它本质上是一种**把注意力运算重排成对系统更友好的方式、从而最小化内存搬运（memory transfer）开销**的巧妙技巧。仅仅是这样，就能带来真正戏剧性的性能提升。

看这组数字：基线 PyTorch 实现（蓝色曲线）在短序列下大概做到 **30~40 TFLOP/s**；而用上 FlashAttention 这种"纯粹的常数因子系统改进"，就能拿到**接近两倍的提升**。更妙的是：在某些规模下，普通实现连**内存都放不下了**（注意力矩阵 $n \times n$ 太大了)，而 FlashAttention 因为**根本不物化（不实例化）那些大注意力矩阵**，依然能继续跑——虽然慢一点。

Tatsu 特意强调：**FlashAttention 并没有解决任何二次方成本问题**，它只是把常数因子压低了——但常数因子就是这么有力量。

## 通往线性时间注意力

不过话说回来，如果目标是 **500 万甚至 1000 万 token 的上下文**，这些小技巧可能就不够用了。我们需要**更激进、收益更大**的手段来支撑长上下文。于是引出了本讲的关键问题：

> **有没有办法让成本（或依赖）与序列长度成线性关系？那样的东西长什么样？**

事实证明，多年来很多人尝试过各种不同的方案，Tatsu 认为其中有几个**失败的起步（false starts）**。但在最近两年左右，出现了一批**在规模化与生产中经受了考验**（effectively battle-tested at scale）的线性时间注意力配方。这正是为什么 2026 版课程**第一次**讲线性时间注意力——因为现在可以确定这些东西真的能在规模化和生产环境里工作。

要解释这些成功的方法，你其实只需要先理解**一个核心思想**，剩下的都是在这个思想上不断展开和叠加。那个核心思想就是——**乘法的结合律（associativity of multiplication）**。

## 本讲路线图

先总结一下本讲的路线图，方便大家把握结构：

1. **线性时间注意力（线性注意力、状态空间模型、混合架构）**：从结合律出发，推导线性注意力及其 RNN 等价形式，再到 Mamba-2、Gated DeltaNet 等大规模验证过的状态空间模型，以及它们的混合比例设计；
2. **稀疏注意力（DSA）**：另一个控制注意力成本的替代路线；
3. **MoE（混合专家)**：什么是 MoE、为什么流行、路由机制、训练方法与系统稳定性。
