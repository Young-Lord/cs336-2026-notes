# 数据的来源：爬虫、限制与 shadow libraries

## "用整个互联网训练"到底哪里不对

你经常能在走廊里听到一句话："**语言模型是在整个互联网（the entire Internet）上训练的**。"Percy 说，这句话其实"类型检查都不过"（doesn't quite type check）——因为如果真的是在"互联网"上训练，那需要一个能上网的 **RL 智能体**，像 agent 一样在网上做事；但预训练并不是这样运作的。

稍微准确一点的说法是：模型训练用的是**公共万维网（public World Wide Web）**。不过这个说法也不完全准确，下面会解释原因。

先看最基本的图景。网络实际上是一堆**活服务器（live servers）**——它们真实存在于世界上，你可以连上去。随便挑一个网站，你都能下载页面：本质就是发一个请求、收一个响应。比如：

```bash
$ curl https://cs336.stanford.edu/
```

但你不能真的在"活服务器"上训练——除非你训练的是一个 RL 智能体。通常的做法是：有一个**爬虫（crawler）**（未必是你自己写的）去抓取。爬虫需要**发现**网上有哪些网页——从一个**种子集合（seed set）**出发——并在爬取过程中把发现的网页**下载**下来。

即便如此，你也没法"跑一趟爬虫就把整个网络的网页全下载下来"。原因是多重的。

## 为什么抓不全：动态内容与认证

**第一类原因是动态内容（dynamic content）**。如今很多网站本质上是一个 App：URL 甚至不再是内容的完整刻画——它只是一个你与之交互的界面，你需要**点击按钮、提交表单**才能访问到内容。比如你想抓 Discord——你没法简单地把 Discord 爬一遍就拿到所有内容。还有大量的内容属于所谓的**深度网络（deep web）**，不是那种"跟着超链接一路爬"的传统网页爬取模型能触达的。

**第二类原因是认证（authentication）**。有些页面需要登录账号（通常还要付费）才能访问：比如 Facebook、X、LinkedIn、纽约时报（The New York Times）。在这些**"围墙花园"（walled gardens）**后面锁着海量的内容。它们技术上确实"在互联网上"，但外人无法用爬虫抓取。当然，如果你就是平台自己，问题就不存在了：如果你是 Facebook，你不需要爬 Facebook——数据本来就在你手里，直接拿来训练即可；如果你是 xAI，你可以直接在 X 上训练。但除此之外的任何人都无法访问这些内容。

## 技术限制：robots.txt、验证码与限速

假设你绕过了认证问题，前方还有潜在的**技术限制（technical restrictions）**。

首先是 **robots.txt**：这是一个通常放在网站根目录下的文件（比如 `nytimes.com/robots.txt`），它告诉你哪些内容允许爬、哪些不允许。它列出了一大堆被禁用（disallowed）的爬虫，比如 OAI-SearchBot、PerplexityBot、ClaudeBot、GPTBot 之类。需要强调：**这不是法律限制，而是一种自律约定**——你理应做个"好公民"，先去读 robots.txt，如果你的名字在名单上，你就不该去爬。这甚至算不上合同，只是"你应该做的事"。

其次，很多网站现在会用 **Cloudflare** 之类的服务检测并拦截机器人活动。你偶尔访问一个网站会看到验证码（CAPTCHA）——那正是因为某种算法怀疑你是机器人，要确认你是人类。如果你真的是机器人，那就过不去（当然你可以尝试绕过，但这是一道实实在在的障碍）。

此外，网站可能封锁某些 **IP 地址**或**国家/地区**，还可能设置**速率限制（rate limits）**。这些都是挡在你面前的现实约束。

## 法律限制：服务条款与许可

然后是**法律限制（legal restrictions）**。网站有**服务条款（terms of service，ToS）**——它说"你要用我的网站，就得遵守这份合同"。而服务条款往往写着："如果你是机器人，请离开"，或者"你不能用本网站的内容做 AI 训练"。即使服务条款什么都没说，网站内容本身可能带有**许可证（license）**，而你未必拥有训练所需的许可。这部分后面会详细展开。

这些限制还在随时间的推移而演化。Percy 提到一篇很好的论文——Shayne Longpre 等人的《**Consent in Crisis**》（同意危机）：作者考察了常用数据集（比如 C4、RefinedWeb、Dolma，后面都会讲到）中 URL 的**技术限制（robots.txt）**与**法律限制（服务条款）**，结论是：**限制在随时间显著增加**。

![Consent in Crisis 的图表：上方为 robots.txt 的限制随时间增长，下方为服务条款的变化](/lectures/13/decline-consent.png)

看上面这张图：上方是 robots.txt 的限制比例——在 2023 年之前，一切基本平稳；但从 2023 年年中开始，"完全禁止"（红色部分）的网站比例突然增长到接近 50%。服务条款也有类似趋势：2016 年几乎没有人在网页上放服务条款，如今大多数页面都有了，而且其中大多数条款明确写着"你不能把它用于 AI"。所以，即使回到 2020 年那个"可以爬网络"的年代，**至少从合法性角度讲，你能爬的网络也比想象中小得多**。

## 爬虫不守规矩的时候

当然，这些说到底都是"指南"，无论有意无意，总有人会违反。于是会出现这样的场面：某个网站（Percy 一时想不起名字了）抱怨 Anthropic 的爬虫在 24 小时内访问了他们的服务器**一百万次**——这显然不好；"Read the Docs"也遭到过类似的冲击。有一段时间（希望现在已经修正了），爬虫在疯狂"锤"各种网站：

![某网站对 Anthropic 爬虫的抱怨：24 小时内被访问一百万次](/lectures/13/anthropic-crawling.png)

值得强调的是，这里的问题**甚至还没牵扯到版权**：无论是违反服务条款，还是单纯制造巨大服务器负载，都会给托管方带来金钱成本，并且劣化其他所有用户的体验。所以说爬取本身就有一堆问题——至于版权，那是另一团更复杂的乱麻，马上就会讲到。

## 影子图书馆（shadow libraries）

最后，网上还有一类东西叫**影子图书馆（shadow libraries）**，它们也是网络的一部分。例子有 **LibGen**（Library Genesis）、**Anna's Archive**、Z-Library、**Sci-Hub** 等。这些网站**完全无视版权、绕过付费墙**：有人收集了海量通常是书籍与论文的数据（这些内容本来都是受版权保护的、需要付费的），把它们免费提供出来。

这些网站收到过大量删除令（takedown orders）、诉讼，并在各个国家被封锁——但通常这些封锁会被规避，它们把服务器放在其他国家继续运作。运营者们的论点是：这等于"把本应免费的东西免费化"。但从法律角度看，这就是**盗版与版权侵权（piracy and copyright infringement）**。后面我们还会回到这个话题。规模上，LibGen 在 2019 年约有 400 万本书，Sci-Hub 在 2022 年约有 8800 万篇论文——这上面堆着大量书籍和论文。

## 小结

到目前为止的结论是：**互联网是巨大的、混乱的，甚至有点吓人的地方**，而你不可能拿到它的全部——既有技术限制，也有法律限制，决定了你能访问什么数据。那么问题来了：**具体该去哪儿找数据、怎么找**？这正是接下来要讲的内容。
