# Lecture 12: Evaluation

**讲师**：Percy Liang · **主题**：评估（Evaluation）

## 本讲内容

上一讲（第十一讲）Tatsu 讲了进阶版缩放定律，这一讲回到 Percy。经过前十讲，我们已经把"训练一个语言模型"所需的全部环节都过了一遍：架构、优化器、主训练循环、用 kernel 加速训练、缩放定律、推理加速。唯一缺的就是**训练数据**——那是下一讲的主题。但 Percy 指出：在谈数据之前，必须先想清楚一个问题——**我们希望模型具备什么行为**？这正是本讲的主题：评估（evaluation）。评估问一个看似简单的问题：给定一个训练好的模型，它有多"好"？但它绝不是一个机械的过程。评估定义了 AI 发展的"北极星"，模型开发者（开源的、闭源的）都把它当作衡量进步的标尺；**你如何设计评估，就在隐含地塑造模型未来能做什么**。整讲围绕一个核心挑战展开：**从抽象的构念（"擅长对话""有帮助"）转化为具体的指标（由具体的提示词或环境驱动）**。

讲次按基准的类型逐层展开。**第一部分**是困惑度（perplexity）：从"语言模型是一个概率分布"这个核心出发，导出困惑度的定义及其与交叉熵的关系，回顾 2010 年代经典的**同分布评估**范式（Penn Treebank、WikiText-103、One Billion Word）与 GPT-2 开创的**零样本跨分布评估**，讨论"perplexity is all you need"这一信念（最优困惑度即真实分布的熵，当且仅当 $p = t$），以及条件困惑度、LAMBADA 与 HellaSwag 这些"披着准确率外衣的困惑度"。**第二部分**是考试类基准：MMLU（57 个科目的知识测验）、MMLU-Pro（清理题目、10 选项、链式思考）、GPQA（博士级"Google 也查不到"的问答，专家 65%、GPT-4 39%、如今约 94%）、Humanity's Last Exam（2500 道多模态题、众包 + 巨额奖金 + 私有留存集），并讨论了基准分数的统计误差与"多选题不难、只是限制问题类型"的观察。**第三部分**是聊天类基准：面对"如何评估开放回答"这一难题，Chatbot Arena（现 Arena AI）用真实用户提示 + 匿名成对比较 + **Elo 评分**（Bradley–Terry 模型的最大似然拟合）来聚合人工偏好，并详细讨论了它的优缺点（真实提示、无需把相同提示喂给所有模型，但人群分布未知、二值偏好混淆风格与正确性、易受谄媚影响）；AlpacaEval 用 LLM 当评委（偏好长答案导致刷榜，2.0 用回归去偏，"如何评估指标本身"——与 Arena 的相关性高达 0.98）；WildBench 用真实聊天记录 + checklist/rubric 提升评委可靠性。**第四部分**是智能体基准：从"说什么"转向"做什么"，SWE-bench（读代码库 + issue、提交 PR、单元测试打分）、Terminal-Bench（终端环境、93 人众包 229 个任务）、CyBench（40 个夺旗 CTF 任务、首次解题时间衡量难度）、MLE-Bench（Kaggle 竞赛），并强调 **agent scaffold（智能体脚手架）** 与语言模型同样重要（显式规划、层级委派、持久记忆、上下文工程）。**第五部分**是纯推理基准与安全评估：ARC-AGI 系列（2019 年 ARC-AGI-1 预训练模型纹丝不动，2024 年 o1/o3 推理模型让分数起飞，2025 年 ARC-AGI-2，2026 年交互式的 ARC-AGI-3）把推理与知识解耦的努力；安全基准 HarmBench（拒绝有害行为）、AIR-Bench（基于监管框架的风险分类学）、越狱攻击 GCG（在开源模型上优化、迁移到闭源模型）、以及"什么是安全"的讨论（高度上下文相关、风险多样、双用途）。**第六部分**是评估的更深层考虑：现实性/生态效度（GDPVal、MedHELM、Clio）与有效性（训练测试重叠/污染的检测——交换性测试、报告规范、新鲜评测、私有评测，以及数据集质量问题——SWE-bench Verified、"空响应拿 38%"等），最后讨论"评估的目的是什么""我们在评估什么（方法 vs 模型/系统）"，收尾总结：**没有唯一真正的评估，选择取决于你想衡量什么**。

## 本讲要点

- **评估塑造 AI 发展**：评估设定"北极星"，模型开发者都拿它当进步标尺；评估的核心挑战是**把抽象构念（"擅长对话"）转化为具体指标**（由提示词或环境驱动）；没有唯一正确的"好"的定义——基准分数、成本效率、人类偏好、市场选择（人们愿意为之付费）是四种互补的视角；
- **困惑度是"评估一个分布"的自然方式**：$PP(D) = p(D)^{-1/\vert D\vert}$，其对数正是交叉熵（每 token 平均负对数似然）；最优困惑度是真实分布的熵，且**当且仅当 $p = t$ 时取得**（$H(t,p) = H(t) + \text{KL}(t\Vert p) \ge H(t)$，Gibbs 不等式）——这就是"perplexity is all you need"的信念：把困惑度压到底就得到了真实分布，从而"到达 AGI"；但这是信念而非科学；
- **从同分布到跨分布评估**：2010 年代的标准做法是在数据集的 train/test split 上测困惑度（Penn Treebank、WikiText-103、One Billion Word）；GPT-2 开创了"在大规模网上数据上训练、在标准基准上零样本评估"的新范式（同分布的小数据集上甚至能超过 SOTA，但 1BW 这类大数据集上不如 SOTA）；
- **困惑度可能"多于你需要"**：它惩罚每个 token 的预测（如"Stanford was founded in 1885"里的 *founded*），解决方法是用条件困惑度 $PP(x \mid c)$；而 LAMBADA（完形填空、精心挑选需要长距离依赖才能消歧的词）与 HellaSwag（多选句子补全）本质上是"披着准确率外衣的困惑度"；
- **考试类基准的趋势是越来越难**：MMLU（57 科目）→ MMLU-Pro（去噪 + 10 选项 + 链式思考，准确率降 16%–33%）→ GPQA（博士级"Google 也查不到"，专家 65%、GPT-4 39%、现在约 94%）→ HLE（2500 题多模态 + 私有留存集，分数仍是个位数到低两位数）；**多选题不限制难度**（可以出得极难），但**限制了可问的问题类型**，且考试不反映真实使用（没人会向助手问 HLE 题）；
- **基准分数要报告统计误差**：准确率/胜率是二项比例，标准误为 $\sqrt{\hat{p}(1-\hat{p})/N}$——HLE 2500 题在 10% 准确率下标准误约 0.6%，AlpacaEval 805 题在 50% 胜率下约 1.8%；"报告置信区间"是评估报告规范的一部分；
- **Arena 用成对比较 + Elo 聚合人工偏好**：$p(A \succ B) = 1/(1+10^{(R_B-R_A)/400})$（Bradley–Terry 模型），用最大似然拟合各模型评分；优点——真实用户提示（免费使用是激励）、**无需把相同提示喂给所有模型**（只需对局图连通）、随时间动态更新；缺点——人群分布未知、二值偏好混淆风格与正确性、人类评委无法真正判断对错、易受谄媚影响；
- **LLM 评委有已知偏差**：AlpacaEval 的 GPT-4 评委偏好更长的回答导致刷榜，2.0 用回归去偏；**如何评估一个指标本身**——与人类（Arena）的相关性是最常用的合理性检查（AlpacaEval 与 Arena 相关性 0.98，但只在被评估模型集合内成立）；**checklist/rubric 让评委（无论人类还是 LLM）更可靠**（WildBench 的做法）；
- **智能体基准评估"做什么"**：SWE-bench（单元测试打分，2024 年约 16% → 现在约 93%）、Terminal-Bench（通用终端环境）、CyBench（CTF 夺旗，从约 10% 到被完全解决）、MLE-Bench（Kaggle）；**agent scaffold 与模型同等重要**——同模型配不同 scaffold 分数不同；现代 scaffold 需要显式规划（todo list）、层级委派（子 agent 返回摘要）、持久记忆（读写文件）、上下文工程；
- **ARC-AGI 试图把推理从知识中剥离**：每个任务独一无二、100% 人类可解，因此记忆无用；预训练模型在 ARC-AGI-1 上纹丝不动（2019–2023），**2024 年推理模型 o1/o3 让分数起飞**，到 2026 年 ARC-AGI-3 分数又回到极低——这既是"推理能力解锁"的证据，也说明解耦推理与知识极难、且 ARC 限定于人类推理；
- **安全评估不止"拒绝有害请求"**：HarmBench（510 种有害行为、期望模型拒绝）、AIR-Bench（基于 EU/中国/美国监管框架与公司政策的 314 类风险分类学）；**越狱（GCG 贪心坐标梯度）可以在开源模型上自动优化提示词、并迁移到闭源模型**；安全高度上下文相关（政治、法律、社会规范因国而异），风险多样（幻觉、谄媚、教唆犯罪、批判思维退化），且具双用途（网络攻击 vs 渗透测试）；
- **现实性（生态效度）**：考试离真实使用最远；GDPVal 用按美国 GDP 前 9 大行业的专业人士（约 14 年经验）造任务、MedHELM 用 29 名临床医生提供 121 项真实临床任务、Clio 用语言模型分析真实用户数据总结使用模式——但现实性与隐私往往矛盾；
- **训练测试重叠（污染）是科学有效性的最大威胁**：无法知道网上训练数据里有什么；四条应对路径——① 交换性检测（基准实例顺序本应随机，模型若表现出对特定顺序的偏好则说明见过）、② 报告规范（模型厂商应报告与测试集的交叠、报告置信区间）、③ 新鲜评测（LiveCodeBench、UncheatableEval，但时间戳也可能被骗）、④ 私有评测（公司内部代码库、个人未公开写作——最适合困惑度）；
- **数据集质量需要持续审计**：SWE-bench 修复成 SWE-bench Verified、GSM8K/MMLU 发现坏题（"没有曲线的图无法作答""婴儿有没有穿袜子？"）、agentic 基准存在平凡解（**空响应也能拿 38%**）、测试用例可能不完备；Docent 用 LLM 审计 agent trace 是"质化地审视量化基准"的好实践——**做基准时永远要亲眼看输出**；
- **评估目的决定评估方式**：购买决策（A 还是 B）、研究（测量"智能"）、政策（理解利弊）、模型开发（反馈改进）需要不同的评估组合；基础模型时代从"评估方法"转向"评估模型/系统"（nanogpt speedrun 是刻意评估算法的例外）；**没有唯一真正的评估**——难度、现实性、有效性各有权衡，必须先明确目标并声明"游戏规则"。
