# 状态空间模型与混合架构：Mamba-2 到 Gated DeltaNet

线性注意力很简单，但有些人会嫌它"太 naive、太简单"——希望里面有更认真、更复杂的神经网络在发生。那么可以做什么？答案是：**回到线性注意力的 RNN 形式，在里面加门控（gating）**。这一节我们会看到，一连串如今在规模上验证过的状态空间模型（State Space Model,SSM），本质上都是线性注意力的一步步"加料"。

## 从线性注意力到 Mamba-2：加一个门控

线性注意力的"主要问题"在于：**它总是把状态原封不动地往前传**。从 LSTM 的"老日子"里我们就知道，重要的是知道**什么时候该把信息传下去，什么时候不该传**——该遗忘的东西要送进零。受这个启发，给状态更新加一个门控 $\gamma_t$:

$$S_t = \gamma_t S_{t-1} + k_t v_t^\top, \qquad y_t = q_t^\top S_t + v_t^\top D, \qquad \gamma_t = f(x_t)$$

这里几个要点:

- $\gamma_t$ 是**输入相关(input-dependent)的门控**,它决定把多少旧状态 $S_{t-1}$ 携带到未来。注意它**没有状态依赖(state-dependent)**——$\gamma_t$ 只依赖当前的输入 $x_t$。这正是保持"对偶性"的关键;
- 正因为 $\gamma_t$ 不依赖状态,我们可以**并行地算出所有 $\gamma_t$**,然后照常应用对偶性:训练时用密集矩阵乘形式,推理时用 RNN 形式;
- 公式里我特意多写了一项 $v_t^\top D$(幻灯片里也标出来了,课上是补上来的):$D$ 是另一个可调的(门控)矩阵,它让当前时刻的值 $v_t$ **直接"直通"到输出**——作用有点像残差连接。它并不是状态更新的核心,但在 Mamba-2 的真实公式里是存在的,这里写全以免大家之后看论文时对不上。

这套公式就是 **Mamba-2**。你可能听说过 **Mamba、Mamba-2,现在还有 Mamba-3**——这是 Albert Gu、Tri Dao 等人提出的一系列状态空间模型。它们原本是从状态空间理论(连续时间状态方程那一套)推出来的,但如果你只看**机制层面**——真正在算什么——它完全可以看成**线性注意力的一个简单推广**。

### Nemotron 3:Mamba 混合的小规模验证

Tatsu 上一讲提到过 **Nemotron 3**,它正是用这个思路做的:**用 Mamba-2 作为"便宜层",每隔几层插入一次大的 softmax 注意力**,以不同的交替方式管理"推理成本 vs 表达力"的权衡。Nemotron 3 用的是大约 **3:1 的 Mamba/注意力混合**,在相当长的上下文下也有不错的吞吐(prefill 与同类模型相当甚至更好),性能可以和 Qwen 3 thinking、GPT-OSS 等比较。当然,这些是**小规模的 frontier 模型**(不是真正的巨模型),但至少说明这套东西**确实能工作**。

## 一个通用规则:只要门控只依赖输入,对偶性就还在

门控的想法很酷,你可能会问:**能不能一直往这个递推里加料,让它越来越复杂?** 可以。这里有一条经验法则(rule of thumb),它概括了在这一系列操作里你能安全做什么:

> 只要你用**只依赖输入(而不依赖状态)的项**去门控 RNN 里的各个项,你就能保持"并行运算(训练) ↔ 串行运算(推理)"之间漂亮的对偶性。

换句话说,**"状态依赖"是破坏对偶性的东西**,而输入依赖的门控是安全的。下面要讲的 Gated DeltaNet 就是在"不越界"的前提下把门控用到了极致。

## Gated DeltaNet:第二个门控与擦除投影子

**Gated DeltaNet 可以说是目前最广泛使用的状态空间模型之一**——它在不少论文里被测试过,并且有一个非常漂亮的大规模验证(就是后面的 Qwen 3.5 / Qwen Next)。它相对于 Mamba-2 做了什么?对比两个更新式:

Mamba-2(再次写出):

$$S_t = \gamma_t S_{t-1} + k_t v_t^\top, \qquad \gamma_t = f(x_t)$$

Gated DeltaNet:

$$S_t = \gamma_t \left(I - \beta_t k_t k_t^\top\right) S_{t-1} + \beta_t k_t v_t^\top, \qquad \gamma_t = f(x_t),\ \beta_t = f(x_t)$$

$$y_t = q_t^\top S_t$$

两个新的东西：

1. **第二个门控 $\beta_t$("无输入操作"门)**：如果 $\beta_t = 0$，就表示"**不把当前信息写进状态**"。这与 LSTM 的思想一脉相承——LSTM 里有"遗忘门"和"输入门"，控制要不要保留旧信息、要不要写入当前时刻的信息。Gated DeltaNet 虽然最初是从完全不同的角度推出来的，但原则与 LSTM 非常相似；
2. **擦除投影子（erasure projector）** $(I - \beta_t k_t k_t^\top)$：这一项继承自 **DeltaNet**（Gated DeltaNet 的前身）。直觉是：当你把当前键 $k_t$ 的信息写进状态时，**不仅想写入新信息，还想顺带擦掉历史上已经写进 $k_t$ 方向的东西**——"不是只往里放，而是要清掉这个键已经贡献过的部分"。矩阵 $I - \beta_t k_t k_t^\top$ 本质上是**把状态中沿 $k_t$ 方向的分量投影掉**（虽然它不是严格的单位向量投影，但直觉大致如此）。

这个更新方向很有意思：Tatsu 提到，**这个投影子已经在不同场景下被"重新发明"过**——如果你去解某些元学习的最小二乘（meta-learning least-squares）问题，就会得到同样的更新式。因此在**快速权重编程（fast weight programming）**或**测试时训练（test-time training,TTT）**这些方向，研究者们从完全不同的设计原则出发，最终得到了几乎一模一样的解。

## Qwen 3.5 / Qwen Next:3:1 的 Gated DeltaNet 混合

Qwen 3.5 以及它的前身 **Qwen Next**，是当前最好的开源模型之一，而它们用的**正是 Gated DeltaNet**:**3:1 的 Gated DeltaNet / 注意力混合**。性能非常合理、推理特性出色——随着上下文长度上升，Qwen Next 的**解码吞吐比 Qwen 3 高出一大截**；与各种闭源/前代模型的性能对比也显示，**混合架构几乎没有伤害性能**。

## 混合架构的性能：比例设计很重要

那么"混合的比例"到底该怎么定？Tatsu 说，目前**好的受控研究（controlled study）不多**，但他知道一项由 **ByteDance Seed 与 UC Santa Cruz** 的合作研究，系统地对比了 Mamba-2、Gated DeltaNet 等架构，扫描"非全注意力层"（RNN 层）的比例。结果有点乱，但值得抓住几个结论：

- 图中虚线是**全注意力（full attention）的性能基线**；从左到右，RNN 层的比例逐渐增加；
- 对于最好的几个架构（黄、橙、蓝——Gated DeltaNet 及其各种变体），在**低混合比例下基本没有性能损失**;
- 一旦超过某个点，**长上下文性能开始明显下降**；走到**纯 RNN（全混合)**时，所有架构都有非常明显的退化；
- 其他评测（比如 QA）也呈现同样的故事：随着混合比例上升，性能**相当稳定而清晰地下降**，直到纯 RNN 的端点。

另外 Tatsu 提了一句：像**单键检索（single-key retrieval）**这类任务，几乎所有长上下文架构都会**显式地优化**它（所以看起来都还不错）；但 QA 这类任务上，混合比例的代价就藏不住了。

## 课堂问答：关于等价性与输出直通项

### 问答：并行形式与循环形式是近似等价，还是精确等价？

（同学：你前面讲到并行形式和循环（linear）形式，它们是不是应该只是近似等价，会有轻微性能下降？)

**Tatsu**：澄清一下，"循环（recurrent）"我指的是**一般的 RNN 表述**——比如 Gated DeltaNet 就是一种递推。要回答这个问题，关键要分清**两个不同的步骤**:

- **第一步（有损）**：从完整 softmax 注意力（$\rho$ 存在）丢掉 softmax、变成线性形式——**这一步是有损的（lossy）**，这是我们所有讨论的起点，损失发生在"丢 softmax"这里；
- **第二步（精确）**：从线性形式到循环（RNN）形式——**这个等价是精确的（exact）**，不是近似。

所以问题中"轻微退化"的担心其实落在第一步：不是并行/循环两种写法不一致，而是"去 softmax"本身要付出表达力的代价。

### 问答：输出里的 $v_t^\top D$ 这一项是什么？

（同学：那个 attention 下面的 $v_t^\top D$ 项是什么？)

**Tatsu**：在（纯）线性注意力的对偶形式里，我们做的是把历史的 $k v^\top$ 累积进状态、再用 $q$ 去"读取"。但你可能希望**输出里也带上当前时刻自己的值 $v_t$**——当前 token 的值对下游任务往往是有用的。所以 $v_t^\top D$ 有点像一条**残差连接（residual connection）**：让当前输入的值**直接穿过注意力**到达输出；而 $D$ 是另一个**可调的门控**，控制直通量的大小。它不是状态更新的核心（上一张幻灯片我道歉没有及时解释），只是 Mamba-2 真实公式的一部分，为了完整性把它补上。

### 一个小结：这套方法收敛到了 LSTM 形状

讲完这些，还有一个值得一提的观察：**很多经过大规模测试的方法，最终都收敛到了这个"漂亮的、简单的、线性注意力风格的循环形式"**。虽然不是没有例外，但大部分东西在终点都变成了**几乎像 LSTM 一样的东西**——带各种输入相关门控的线性递推。这个观察，在 DSA 那部分和最后总结时还会再出现。
