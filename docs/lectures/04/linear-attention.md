# 线性注意力：从结合律到 RNN 等价

线性时间注意力这一系列方法，核心只有一个思想：**乘法的结合律**。先把普通注意力的数学形式写下来，再看丢掉一个东西之后，我们能做什么。

## 注意力回顾：全对全交互与 softmax

用紧凑的记号，自注意力（self-attention）可以写成：

$$\mathrm{Attn}(Q, K, V) = \rho\!\left(Q K^\top\right) V$$

其中 $Q \in \mathbb{R}^{n \times d_k}$、$K \in \mathbb{R}^{n \times d_k}$、$V \in \mathbb{R}^{n \times d_v}$,记号上方标出的正是矩阵的维度。流程是:

1. 取 $Q$ 和 $K$ 做矩阵乘法,让**所有 $n$ 个位置两两交互**(all-to-all);
2. 用 softmax(即这里的 $\rho$,按行归一化)把它们变成注意力权重;
3. 再乘以 $V$,得到注意力输出。

这就是经典的注意力操作,复杂度是二次方的——因为 $QK^\top$ 这一步要做 $n^2 d_k$ 次乘法,而 $n$(上下文长度)可能高达数百万。

现在,为了讨论起见,**暂时忘掉 softmax,把 $\rho$ 当成恒等映射丢掉**。如果 $\rho$ 是恒等的,我们就能改变这个操作的复杂度。

## 核心推导:结合律把"平方"变成"线性"

回顾一下,注意力原本是:

$$\mathrm{Attn}(Q, K, V) = (Q K^\top) V$$

它的代价拆开来看：

- 计算 $QK^\top$:$\ n^2 d_k$;
- 再乘 $V$:$\ n^2 d_v$;

合计 $O(n^2 d_k + n^2 d_v)$——**两个 $n^2$ 项**，这就是"昂贵"的来源，因为 $n$ 是百万量级。

但矩阵乘法满足结合律，所以当 $\rho$ 是恒等映射时，我们可以**把括号挪一下**:

$$Q K^\top V = Q\,(K^\top V)$$

这一步"非常傻,但出奇地重要"。重新分析代价:

- 先算 $K^\top V$:$K^\top$ 是 $d_k \times n$,$V$ 是 $n \times d_v$,乘积是 $d_k \times d_v$,代价 $n d_k d_v$;
- 再算 $Q\,(K^\top V)$:$Q$ 是 $n \times d_k$,乘以 $d_k \times d_v$,结果是 $n \times d_v$,代价也是 $n d_k d_v$。

合计 $O(2 n d_v d_k)$。我们实际上只是**把"哪部分是二次方"换掉了**:

$$\underbrace{n^2 d_k + n^2 d_v}_{\text{原来:对序列长度 } n \text{ 二次方}} \quad\Longrightarrow\quad \underbrace{2\,n\,d_v\,d_k}_{\text{现在:对 } n \text{ 线性,对隐藏维度二次方}}$$

![](/lectures/04/slide-04.png)

关键就在于，新的二次方项依赖的是 $d_k$、$d_v$——**隐藏维度（hidden dimension）**。隐藏维度在原则上可以很大，但实际模型里通常只有**几千到几万**，不会有人在自己的隐藏状态里放一百万个坐标。相比之下，把依赖放在 $n^2$（百万量级的上下文长度）上要可怕得多。所以这是一个对序列长度**友好得多的依赖形式**。

这是本讲你要记住的第一件事：**乘法的结合律允许我们改变对序列长度的依赖**。这个想法本身并不新鲜——它就是**线性注意力（linear attention）**（如 Shen 等人 2018 年的工作；Katharopoulos 等人 2020 年给出了核方法（kernel）版本)，并且与"快速权重编程（fast weight programmers）"等思想有联系。

## RNN 等价形式：状态携带

结合律重排还有更妙的地方——它直接导向了 RNN 形式的等价物。回到自注意力的场景，考虑重排后的矩阵乘 $Q(K^\top V)$。右边的 $K^\top V$ 这一项，可以**不写成密集矩阵的形式，而是从左到右逐步增量地算**:

$$S_t = S_{t-1} + k_t v_t^\top, \qquad y_t = q_t^\top S_t$$

这里 $k_t$、$v_t$、$q_t$ 分别是第 $t$ 个位置(timestep)的键、值、查询向量。$S$ 是一个**状态(state)**:每来一个 token,我们就把它的外积 $k_t v_t^\top$ 累积进状态;输出 $y_t$ 则是查询与当前状态的乘积。上面的密集形式与这个 RNN 形式是**等价的**——只是把"一次性做完的矩阵乘法"拆成了"逐 token 增量更新"。

让我们把这个等价的直觉展开写一遍。注意在因果(causal)情形下,第 $t$ 个位置的输出只应该看它之前的位置,那么:

$$y_t = q_t^\top \sum_{s \le t} k_s v_s^\top$$

把它拆开看，这恰好就是 $S_t = S_{t-1} + k_t v_t^\top$（初始 $S_0 = 0$）递推下去的结果。也就是说，**"把键值外积累积成状态"和"对所有历史做一次矩阵乘"是同一种计算**。

### 训练用并行形式，推理用串行形式

这一步为什么重要？因为 RNN 形式有一些非常好的性质，也有一些不好的性质，而线性注意力**两头的好处都要**:

- **推理（inference）**:RNN 太棒了。推理时你有一个固定大小的状态 $S$（尺寸 $d_k \times d_v$)，只需要**把这个状态一路携带下去**——每生成一个 token 更新一次状态，内存占用与历史长度无关；
- **训练（training）**：纯 RNN 的训练体验很差（串行、不可并行化），但线性注意力可以用**上面的密集矩阵乘形式**——它是**并行的**，天然适合 GPU 上的大批量训练。

于是这套"对偶性（duality）"给你**鱼与熊掌兼得**:**训练用并行的、二次方的密集形式；推理用串行的、线性的 RNN 形式**。

顺带一提，如果你在状态更新时给 $S_{t-1}$ 加一个衰减权重 $\gamma$（即 $S_t = \gamma S_{t-1} + k_t v_t^\top$)，就得到了 **RetNet** 这类工作——这条路上其实还有不少已经存在多年的分支。

## 但线性注意力的表达力是受限的

在依赖关系这个层面，这套方案非常漂亮。可惜的是，**纯线性注意力本身很"线性"，表达力（expressivity）不够好**。Tatsu 的原话是："不幸的是，这东西是线性的，这不太好。"——这是后面所有讨论的起点：我们要在这个基础上不断给它"加料"。

## Minimax M1：朴素线性注意力也能在规模上工作

在讲那些加料版本之前，先看一个好消息：即使是最朴素的线性注意力，也有人把它用到了大规模。

**Minimax M1**（以及 minimax-text-01）是一个相当大规模、高性能的中国开源模型，它使用 **7:1 的混合结构**——每 7 层线性注意力搭配 1 层完整的 softmax 注意力。它的性能总体很强：可以和 OpenAI 的 **o3**、**DeepSeek R1** 这些强模型放在一起比较，相当有竞争力。而且由于大部分层是线性注意力，它对上下文长度的依赖**大部分是线性的**——不是完全线性（毕竟还有那些 softmax 层），但代价温和得多。

![](/lectures/04/slide-06.png)

这里 Tatsu 特意强调了一个诚实的观察：

> **到目前为止，还没有人证明过纯线性时间注意力（fully linear-time attention）能在大规模上工作。** 接下来要讲的所有东西，都是某种**混合（hybrid）**——必须保留一部分全连接（二次方）的 softmax 注意力。

Minimax M1 的 7:1 就是一个例子：线性注意力提供便宜的计算，而少量全注意力提供表达力。这为下一节"从线性注意力到 Mamba-2"埋下了伏笔——混合的思路贯穿始终。

## 一个小实验：并行形式与串行形式的代码

为了把"对偶性"落到实处，这里给一个教学用的最小实现。两种写法在数学上严格等价（在去掉 softmax 的前提下），只是计算顺序不同：

```python
import torch

torch.manual_seed(0)
n, dk, dv = 8, 16, 8
Q = torch.randn(n, dk)
K = torch.randn(n, dk)
V = torch.randn(n, dv)

# 形式一:密集(并行)形式 —— 训练友好
Y_dense = Q @ (K.T @ V)          # 先算 K^T V (dk x dv),再乘 Q —— O(n·dk·dv)

# 形式二:RNN(串行)形式 —— 推理友好,状态固定大小
S = torch.zeros(dk, dv)
Y_rnn = torch.empty_like(V)
for t in range(n):
    S = S + K[t].outer(V[t])     # S_t = S_{t-1} + k_t v_t^T
    Y_rnn[t] = Q[t] @ S          # y_t = q_t^T S_t

print(torch.allclose(Y_dense, Y_rnn, atol=1e-6))   # True
```

注意这里为了直观，`Y_dense` 没有做因果掩码；真实的因果线性注意力会让每个位置只累积它之前的状态，但"两种形式等价"这一点是完全一样的。
